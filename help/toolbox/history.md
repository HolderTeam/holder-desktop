# History

History shows how the selected card reached its current saved version.

Holder reads this timeline from the project's Git repository. Nearby automatic saves are grouped
into editing sessions, while moves, links, milestones, deletion, restoration, and merges remain
distinct events.

Select an event to compare that saved version with the current saved version. History is read-only
in this first release: it does not change the card, working tree, or repository.
